# 账号备注设计

[English](2026-09-09-account-remark-design.en.md) | 中文

## 目标

账号池表格不再显示 UID 列。最右侧新增可编辑的“备注”列，同时保留 UID 作为账号主键和内部路由标识。

## 数据与接口

- `accounts` 表新增可空的 `remark TEXT` 字段，启动时通过幂等迁移添加。
- 已有账号的备注默认为空。
- 重新导入同一 UID 的账号时保留已有备注。
- 新增管理员接口 `PATCH /ui/accounts/{uid}/remark`，请求体为 `{ "remark": "..." }`。
- 备注去除首尾空白，允许空字符串清空，最大长度为 200 个字符。
- 账号不存在返回 404，字段类型错误或超过长度返回 400。
- 接口只更新 `remark`，不修改账号凭据、状态或配额。

## 前端交互

- 账号表移除可见的 UID 列。
- “备注 / Remark”列位于表格最右侧，即操作列之后。
- 备注单元格默认显示文本；空值显示“添加备注 / Add remark”。
- 点击进入编辑，按 Enter 或点击保存按钮提交，按 Escape 或点击取消按钮放弃。
- 保存期间禁用当前编辑器并显示进度；成功后立即更新本地账号数据，失败时保留编辑内容并显示错误提示。
- 搜索继续匹配账号名和内部 UID，并新增备注匹配。

## 兼容性与验证

- UID 仍用于激活、启停、刷新、删除、日志筛选和请求路由。
- 后端测试覆盖迁移幂等性、鉴权、保存、清空、长度限制、404 和重新导入保留备注。
- 前端通过 TypeScript 检查、构建和服务器页面交互验证。
