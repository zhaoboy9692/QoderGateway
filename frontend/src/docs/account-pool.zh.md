# 账号池

[English](account-pool.md) | [中文](account-pool.zh.md)

账号池管理已有 Qoder 会话，供请求路由和账号级失败切换使用。

## 导入方式

- **添加 PAT**：使用 Qoder Personal Access Token 换取会话。
- **导入账号**：选择本项目导出的 JSON 文件，或粘贴包含 `user_id`、`token`、`refresh_token` 等字段的账号 JSON。

账号按 `uid` 去重。重复导入更新已有记录，不新增同 UID 账号。禁用账号保留在数据库中，但不参与路由。

## 可编辑备注

账号表仍将 UID 用作内部路由标识，但不再把它显示为一列。最右侧是可选的持久化备注：点击已有内容或“添加备注”即可编辑，按 Enter 或点击保存提交，按 Escape 或点击取消放弃草稿。空值用于清除备注，最长 200 个字符。

账号搜索同时匹配账号名、内部 UID 和备注。重新导入相同 UID 时，未提供的字段（包括备注）会保留；备份中提供的字段会覆盖原值。

## 当前账号与轮转

当前账号优先处理请求。只有被识别为账号级的问题才会触发轮转；一般上游错误不会直接跳过账号。遇到额度错误时会再查询额度，查询失败或数据不足时不会据此轮转。

## 默认显示 Credits

首次进入账号池自动加载限额表；切换页面或点击“查看限额”复用本次页面会话的结果，包括查询失败状态。需要重新查询时点击刷新。刷新整个浏览器页面后会重新自动加载一次。

| 数据 | 含义 |
| --- | --- |
| `userQuota.total / used / remaining` | 订阅席位总额、已用及剩余 |
| `orgResourcePackage.cap / used / remaining` | 组织资源包总额、已用及剩余 |
| `orgResourcePackage.available` | 资源包当前是否可用 |
| `isQuotaExceeded` | 上游明确报告的额度耗尽状态 |

资源包可能由同一组织的多个账号共享，不要重复相加。席位余额为零而可用资源包仍有额度时，不能仅据此判定账号耗尽；上游明确返回 `isQuotaExceeded: true` 时仍以其为准。未返回的数值显示为未知，查询失败显示错误。

## 刷新额度与账号资料

- **查看限额**：定位到已有额度表，不查询上游。
- **刷新 / 刷新状态**：查询启用账号的额度，并同步套餐和重置日期。
- 每行的**刷新**：只更新该账号；结果同步到限额表。
- **刷新 Token**：更新登录凭据，不等同于查询额度。

刷新有旋转图标、额度表闪动、查询完成时间和结果提示。余额未变也会确认查询已完成。

| 字段 | 含义 |
| --- | --- |
| `plan` | Qoder 套餐标识 |
| `user_tag` | 套餐展示名称，例如 Teams |
| `next_reset_at` | 上游 `nextResetAt` 时间戳，页面显示为日期 |
| `quota` | 旧版额度字段，不作为 Credits 余额展示 |

未获取套餐时显示“未获取套餐”，不会默认显示 Trial。资料刷新失败保留上次成功数据。界面的日期按浏览器时区显示。

## 导出备份与自动调度

**导出账号**下载 `qodergate-accounts-日期.json`，包含登录 Token、刷新 Token、设备标识、启用状态、备注及当前手动账号；不包含网关密码或 API Key。文件含敏感登录凭据，请勿分享或上传 Git。

导入支持该备份格式（`format: qodergate-accounts`、`version: 1`、`accounts` 数组），也兼容旧版 `user_id` / `token` 字段。单次最多 1000 个账号，页面文件上限 8 MB。按 UID 合并，缺失字段保留旧值，格式错误会整批回滚。列表中未包含的账号不会删除。

**自动调度账号**默认关闭，设置重启后保留。开启后无需手动激活：请求在已启用且确认有个人或可用团队额度的账号之间轮转。额度缓存最长 60 秒，首次检查最多并发查询 4 个账号；刷新额度或导入账号会清空相关缓存。额度查询失败、额度未知、明确耗尽和禁用的账号不参与调度。没有可用账号时返回 HTTP 503。

账号凭据错误或已确认额度耗尽时，在响应开始前尝试其他账号，失败账号暂停使用 60 秒。普通网络错误不切换；流式响应开始后的错误不会重新发送请求。关闭自动调度后恢复原手动账号。

管理接口均需要 `X-Gateway-Token`：`GET /ui/accounts/export` 导出，`POST /ui/accounts/import` 导入，`POST /ui/accounts/scheduling` 携带 `{"enabled": true}` 开启调度（`false` 关闭）。旧 `/ui/accounts/batch-import` 仍兼容 JSON 导入。
